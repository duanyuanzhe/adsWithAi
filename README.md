# adsWithAi

广告投放相关 Agent / AI 项目调研与可复用方案。

收录范围严格限定为广告投放自动化、广告账户与 Campaign 管理、竞价与预算优化、受众定向、用于投放的广告素材生成与优化，以及广告效果分析、归因和媒体购买。每个项目都须有第一方文档或具体功能证据；通用 Agent、泛营销工具和仅推测可改造成广告用途的项目不纳入。分析类项目可以只读，素材类项目可以不连接广告账户。

日报比较可核实的热度、能力、应用价值与验证边界；区分较高关注度项目和早期专项观察，没有合适项目时明确记录，不凑数量。功能证据尽量固定到具体提交，GitHub 统计保留采集时间和快照。
