# adsWithAi

广告投放 Agent / AI 项目的定期调研报告。只收录有第一方证据、直接服务广告账户与 Campaign、竞价与预算、受众定向、投放素材、效果分析与归因或媒体购买的项目。

报告比较 GitHub Stars / Forks、代码推送、核心能力与业务价值；明确托管服务、Skills、参考架构与可部署实现的边界。通用 Agent、普通 AI 工具、没有直接广告能力的泛营销项目和推测改造用途均不纳入。无合适项目时直接记录，不凑数量。
