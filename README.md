# adsWithAi

广告投放 Agent / AI 项目的定期调研报告。只收录第一方资料或源码明确服务于广告账户与 Campaign、预算竞价、受众定向、广告素材/feed、效果分析与归因或媒体购买的项目。

比较可核实的热度、核心能力与投放价值，分别说明应用实现、托管客户端、广告 Skills 和研究原型的边界。通用 Agent、推测改造用途及没有直接广告能力的泛营销工具均不纳入；没有合适项目时明确记录，不凑数量。
