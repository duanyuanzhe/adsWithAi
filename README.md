# adsWithAi

广告投放 Agent / AI 项目的定期调研报告。只收录有第一方证据、直接服务广告账户与 Campaign、预算竞价、受众定向、投放素材、效果分析与归因或媒体购买的项目。

报告比较可核实的热度、功能和业务价值，并说明托管服务、广告 Skills、研究原型与可部署实现的边界。通用 Agent、普通 AI、没有直接广告能力的泛营销项目或推测改造用途均不纳入；没有合适项目时明确记录，不凑数量。
